Je pakketten laten samenwerken: koppelingen uitgelegd

De meeste bedrijven gebruiken vier tot tien pakketten die niets van elkaar weten. Een koppeling lost dat op.

Wat is een koppeling?

Software die gegevens van het ene pakket naar het andere brengt, volgens jouw regels. Een bestelling uit de webshop wordt een factuurvoorstel; een gesloten werkbon verandert de status bij de klant.

Hoe het technisch kan

  • Via een interface (API) die het pakket aanbiedt.
  • Via een exportbestand dat op vaste tijden ingelezen wordt.
  • Soms via een bestaande tussenschakel.
  • Lukt het niet, dan zeggen we dat.

Waar je op let

Elk pakket laat iets anders toe. Verandert de leverancier iets, dan moet de koppeling mee: daarom hoort ze bij onderhoud. Een migratie naar een nieuw pakket is een eenmalige koppeling, en vaak meer werk dan men denkt.

Vertel wat vastloopt

Een eerste gesprek kost niets en verplicht tot niets. Je krijgt een eerlijk antwoord, ook als dat «niet bij ons» is.
